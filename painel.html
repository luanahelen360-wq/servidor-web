Sobre o projeto

O WEB SERVER é um projeto desenvolvido com o objetivo de apresentar conceitos e tecnologias relacionados à Engenharia de Telecomunicações.

Nosso propósito é compartilhar informações sobre sistemas de comunicação, redes e tecnologias utilizadas para conectar o mundo.
